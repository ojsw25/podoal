포도알

개인정보처리방침

포도알(이하 '사이트')은 회원가입 없이 쓰는 티켓팅 연습 사이트입니다. 사이트는 방문자의 개인정보를 서버로 수집하거나 보관하지 않습니다. 이 문서는 사이트가 어떤 정보를 어디에 저장하는지 설명합니다.

1. 수집하는 개인정보

없습니다. 사이트에는 회원가입, 로그인, 결제 기능이 없고, 운영자가 관리하는 서버나 데이터베이스도 없습니다. 이름, 연락처, 결제 정보 등을 입력받지 않습니다.

2. 내 브라우저에만 저장되는 정보

아래 정보는 방문자 기기의 브라우저 저장소(localStorage)에만 저장되며, 운영자나 다른 사람에게 전송되지 않습니다.

  • 연습 설정(공연장, 난이도, 모드 등)과 화면 테마
  • 연습 기록, 구간별 최고 기록, 티어, 업적, 오늘의 도전 기록
  • 랭킹에 표시할 닉네임과 내 순위 기록
  • 내 오픈 일정에 직접 등록한 공연 이름과 날짜
  • 보스전 기록과 소리 설정

이 정보는 기기와 브라우저마다 따로 저장됩니다. 지우려면 브라우저 설정에서 이 사이트의 '사이트 데이터' 또는 '쿠키 및 사이트 데이터'를 삭제하면 됩니다.

3. 친구 도전 링크

보스전의 '친구에게 도전 보내기'를 누르면 닉네임과 내 기록이 링크 주소 안에 들어갑니다. 이 링크를 받은 사람은 그 닉네임과 기록을 볼 수 있습니다. 링크는 방문자가 직접 보낼 때만 전달됩니다.

4. 쿠키, 방문 분석, 광고

사이트는 자체 쿠키를 쓰지 않고, 방문 분석 도구와 광고를 사용하지 않습니다. 앞으로 분석 도구나 광고를 도입하게 되면, 도입하기 전에 이 문서에 수집 항목과 목적, 거부 방법을 먼저 적겠습니다.

5. 외부 서비스

사이트를 화면에 표시하기 위해 아래 외부 서비스에서 파일을 불러옵니다. 이 과정에서 방문자의 IP 주소와 브라우저 정보 같은 접속 정보가 각 서비스 제공자에게 전달될 수 있으며, 그 처리는 각 제공자의 방침을 따릅니다.

  • GitHub Pages: 사이트 호스팅
  • esm.sh: 화면을 그리는 프로그램(React) 제공
  • jsDelivr, Google Fonts: 글꼴 제공

6. 실제 예매와의 관계

포도알은 실제 공연장·예매처와 무관한 연습용 사이트입니다. 실제 예매처에 접속하지 않으며, 실제 예매나 결제는 이루어지지 않습니다. 연습과 랭킹에 나오는 다른 이름은 가상의 경쟁자입니다.
